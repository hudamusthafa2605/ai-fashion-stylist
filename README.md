# ✨ AI Fashion Stylist

An AI-powered fashion recommendation system built using Machine Learning, Python, FastAPI, and a web frontend.

## 🌟 Features

- 🎨 Recommend outfits based on color
- 👤 Filter by gender
- 🎉 Filter by occasion
- ☀️ Filter by season
- 👕 Filter by fit type
- 🧵 Filter by fabric
- 💰 Filter by maximum price
- ⭐ Shows a matching score for each recommendation
- 🛍️ Provides product links
- 🖼️ Displays product images

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- FastAPI
- HTML
- CSS
- JavaScript
- Joblib

## 🤖 Recommendation System

The system uses encoded fashion features and cosine similarity to find products that best match the user's preferences.
